========================================
  QuickMenu 快启  v1.0
  双击热键，快速呼出启动菜单
========================================

【基本用法】
  1. 双击 Ctrl 键（快速按两次）→ 呼出图标宫格菜单（手机桌面式）
  2. 输入关键字过滤（支持中文、拼音关键词、路径）
  3. ↑ / ↓ / ← / → 移动选择，Enter 打开，双击图标也可打开
  4. 右键图标 → 操作菜单：移到开头 / 上移 / 下移 / 移到最后 / 编辑… / 删除
     （删除需再点一次确认）；按住图标拖到另一个图标上可交换位置
     —— 所有调整立即保存生效
  5. Esc 随时退出（无论焦点在哪）；点击其他窗口/桌面空白处 → 自动收起
  6. 再次双击 Ctrl → 关闭菜单
  7. 程序常驻系统托盘，右键托盘图标可：
       - 打开快速菜单 / 设置… / 编辑配置文件 / 重新加载配置
       - 开机自动启动（勾选）
       - 退出

【AI 对话（✨）】
  默认本机 Harness 模式：直接和本机运行的 DeepSeek Harness 对话，
  零配置、无需 API 密钥（Harness 需在本机 127.0.0.1:3080 运行）。
  会话管理：
    - 「桌面助手」分组：通过 QuickMenu 进入的对话都在该分组
      （会话 cwd=桌面目录），会话下拉默认只显示本分组
    - 设置 → AI 对话 可勾选「显示全部会话」
    - 「新建会话」按钮创建新的桌面助手会话
    - 会话下拉显示聊天主题（Harness 自动总结），黑色字体
  其它设置：
    - 接入方式：本机 Harness（默认）/ OpenAI API
    - Harness 地址（默认 http://127.0.0.1:3080）
    - 会话策略：留空=最近桌面助手会话，new=每次新建，或填 sessionId
    - OpenAI 模式：接口地址 / 模型 / API 密钥 / 系统提示
  用法：
    - 呼出菜单 → 点搜索框右侧 ✨ → 打开 AI 对话窗口
    - 输入问题回车发送，流式回复，实时显示 agent 状态；授权/提问时有操作条
    - 搜索无结果时会出现「✨ 用 AI 回答：xxx」，点击直接提问
    - Esc 关闭对话窗口

【图形化设置（推荐）】
  点击菜单底部齿轮 ⚙，或托盘右键 →「设置…」：
    - 呼出快捷键：点击按钮后，直接按下想用的键即可
      （支持 Ctrl / Alt / Shift / CapsLock / Win）
    - 双击判定间隔：滑块 200~600 毫秒
    - 外观主题：自动 / 浅色 / 深色
    - AI 对话：接口地址 / 模型 / API 密钥 / 系统提示
    - 菜单项：管理常用软件/网页/文件夹列表
  点「保存」立即生效，无需重启，也不用改配置文件。

【菜单项管理（支持拖拽！）】
  设置窗口下方是「菜单项」列表，可以直接从桌面 / 资源管理器
  把文件、快捷方式、文件夹拖进去；也可以把浏览器地址栏的
  网址文字拖进去。自动识别类型：
    .lnk 快捷方式 → 解析目标（exe→程序，文件夹→文件夹）
    .url 网页快捷方式 → 自动读取网址
    .exe → 程序；文件夹 → 文件夹；其他文件 → 文件
    网址文字 → 网页
  也可以点「添加」手动填写，双击条目编辑，删除/上移/下移调整。
  快捷方式：直接把文件拖到弹出的快速菜单上，立即添加并保存！

【配置文件】
  首次运行会在程序目录生成 QuickMenu.config.json，
  高级选项可手改（保存后重新呼出菜单即生效）。
  条目类型：
    app     程序（填名称会自动在 PATH 中查找，如 notepad）
    url     网页链接
    folder  文件夹
    file    文件（用默认程序打开）
    command 命令（如 control）

【常见问题】
  Q: 双击 Ctrl 没反应？
  A: 可能与其他软件的热键冲突，打开设置窗口换一个按键
     （推荐 Alt 或 CapsLock）。
  Q: 找不到某个程序？
  A: 在配置里把 Path 写成完整路径，例如
     "C:\\Program Files\\xxx\\xxx.exe"。
  Q: 需要管理员权限吗？
  A: 不需要。程序以普通权限运行，可开机自启。

【卸载】

  - 便携版：运行 卸载QuickMenu.bat
